【过时】用Canta删除手机自带的系统软件！

发表于2024-02-15|更新于2025-04-05
|总字数:361|阅读时长:1分钟

前言

这里是2025年的天影大侠，Android删除系统软件的话用adb很方便了，这就是给懒人的一个麻烦方式，没有意义，如果root了的话，scene更方便，如果没root的话建议不要去动系统软件。

问候

今天分享一个无需root即可删除安卓手机自带app的软件，Canta!

GitHub - samolego/Canta: Uninstall any Android app without root (Shizuku)!

要用到软件！

shizuku和canta它自己！

在这里看看Shizuku

canta的github见上文

到相应的网站下载最新版本

第一步，shizuku激活！

这一步网上教程很多很多，大家可以去别的地方看看

毕竟懒得抄过来

这是官方的教程: https://shizuku.rikka.app/zh-hans/guide/setup/

第二步，开始删除了！

安装好下载的Canta，它会先请求shizuku权限，允许就好

然后就能删除各种软件了包括系统软件

删除了还有记录，可以恢复，神奇的东西

一些没用的话

这个软件其实很简单，就是用adb命令删除软件

如果你想试试的话，可以在shizuku runner里直接输入pm uninstall -k –user 0 [应用包名]

或在其他终端里输入adb shell pm uninstall -k –user 0 [应用包名]

但有现成的软件，为啥要自己动手呢

最后吐槽一下，小米自带的浏览器还没用就1GB，不如via，几MB的大小

#安卓类原生使用分享

分享一下类原生使用的一些小经验

都需要root后并且有核心破解与lsposed
有点多，可以在右下角使用目录

一.DSU

GitHub DSU-Sideloader

dsu是安卓11以上自带的一个功能，可以快捷地侧载一个系统，两个系统都可以正常使用，如设置密码等等。使用dsu-sideloader可以最快捷地体验一下类原生，毕竟不推荐给自己的主力机直接刷。

dsu可以刷入通用镜像gsi或者你系统的类原生包等，

通用镜像在这找到Generic System Image (GSI) list · phhusson/treble_experimentations Wiki · GitHub

如果是做好了的类原生rom话，把payload.bin里的除了boot，dtbo，vbmeta和vbmeta为前缀的其他分区提取出来又压缩到一个zip里，放进dsu-sideloader即可，其他定制的系统也可以试试

如果是gsi的话，就会有很多bug，如自动亮度跳跃，ims无法注册导致收发不了电话信息，所以最好找自己系统的包

二.美化

iconify

这个用过类原生的应该都会用，aosp一般的美化都是这个软件，如果你的系统自带的美化足够的话推荐不用，因为用它容易系统界面死机等等问题，当然你可以把它后台保好，或者只使用lsposed区里的功能

状态栏把窗口级模糊处理打开，模糊度设置为70可有如下效果

Github链接: iconify

colorblendr

这个是用来改material you配色的，可以把md3设计的软件背景色改亮一点或者改改配色，虽然不得不说背景是那种淡色的好丑，不如纯白

Github链接:colorblendr

小窗

一些系统都把米窗整合了进去，链接在这，支持安卓8到14

Github:Mi-Freeform

安卓15的话有从RisingOS提取出来的，下载链接123网盘 提取码：1ESM

当然自己更喜欢用二改的flyme样式米窗，更好看，可以原版米窗侧边栏和flyme样式的小窗一起用

Flyme样式二改米窗Github:Flyme-FreeForm

负一屏

Google的广告机负一屏没人想用吧，可以用SmartSpacer替换成放安卓小部件的

Github:Smartspacer

在lsposed里要勾选桌面启动器和Google应用

只打开相应的负一屏功能就行了，里面的本机smartspace等功能不用开，开了经常需要重启系统界面

负一屏可以改成这种

图标包

图标包去酷安里找找就行了，一般的系统在更改图标包后只是更改了桌面图标，如果想要系统全覆盖的话(如最近任务卡片上)，可以用这个模块，Github:GitHub - RichardLuo0/global-icon-pack-android: An Xposed module for applying icon packs globally

字体和emoji

字体的话可以用这个字体模块，把你想更换的字体ttf放进去就行了

Github: # CJK 字体 Magisk 模块模板

但安卓15好像没用，所以又因为一般的系统都会内置字体选择，可以选inter-vf，harmonyos-sans，ubuntu等字体，就可以直接把字体文件重命名为如ubuntu.ttf，然后用模块放进system/product/fonts里，再在系统的字体选择里选择ubuntu就行了

emoji的话能找到很多ios的emoji模块，但觉得华为的更好看一点，所以用的华为的，分享一下123网盘提取码：DLjW，把它命名为NotoColorEmoji.ttf后也放到system/product/fonts即可

华为emoji长这样

通知图标

把有些空白通知图标改为矢量图标的，不用的话有些通知看起来很难受，或者可以在iconify里打开彩色通知图标，像其他系统一样

Github:NoticeFix

三.功能

Thanos

压后台，划卡关闭应用，管理自启动等，不用它的话一晚20格电有好受的，是付费软件，没r的话只能自显神通了，免费功能也够了。

Github:GitHub - Tornaco/Thanox: I am thanos! 😈 👌

mi-push

推送的，比hms麻烦一点，但酷安和QQ都接入了，还可以自定义通知格式，使用文档看这MiPush Framework使用指南

下载时要下载最新版的，看版本号，它网盘里的排序100是排在2前面的，要自己找最新版的，旧版可能用不了

墓碑

怎么说呢，要用的可以用，我用的n11内核版本太低了，用起来并不好。

还是分享一下

freezer

no-active

freezeit 额这个没更了，酷安有二改的还在更，可以试试

四.一些bug修复

酷安闪退

大概率Selinux宽容问题，可以找模块或者shell输入setenforce 0 暂时解决

收发不了电话和短信

如果你用的gsi的话，能打电话发短信才奇怪，如果是做好的rom话，一般不会有这个问题，如果有，用pixel ims弄一下，还不行的话网上说的要重刷底包，我建议的话，不刷系统算了

用了魔法后某蓝底软件还是连接不上

一些类原生连了梯子，某蓝底软件还是一直显示连接中，我这CrDroid和基于它的系统都这样，在Clash设置里关闭 允许应用绕过 可以解决

五.其他

系统软件

类原生上Google和moto的都好用，moto全家桶可在酷安找到，我这甚至找到了小米的大部分系统软件给类原生的mod版，大家想用的也自显神通找找吧

其他软件

语燕输入法

Github:GitHub - gurecn/YuyanIme: 语燕拼音输入法-一款基于Rime定制开发的九键、全拼、双拼、手写、火星文等方案、支持悬浮、单手、数字行等键盘模式的中文输入法

这是基于Rime的一个输入法，做的比其他同类输入法要更易用更美观，虽然和搜狗，百度等比起来还是略逊一点。

清浊

一个清理内存的软件，还有一言诗词小部件，负一屏上放的就是它，可以在酷安找到
